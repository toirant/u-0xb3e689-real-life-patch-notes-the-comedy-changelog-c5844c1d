# Real-Life Patch Notes: The Comedy Changelog

Entry for the [make.fun bounty "Real-Life Patch Notes: The Comedy Changelog"](https://make.fun/competitions/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d) — write the funniest one-line patch note for a bug in real life or human biology, 160 characters max. Free entry; the top 5 places split the $5 reward pool equally.

## The entry

> v1.9.2: fixed a bug where the brain replayed your most embarrassing moment from 2014 at 3am instead of letting you sleep.

121 characters, one line, in the terse register of a real release note: a version number, a dry engineering tone, and a bug every human recognises at once — the brain's 3am replay of the thing you said in 2014.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (created if missing). The program validates the entry first: 1–160 characters, not only whitespace, single line. Two runs produce byte-identical output.
